# Safe C: Cleaner 0.5.1 — test checklist

## Quick Clean compact UI

1. Открыть «Быстрая очистка» и убедиться, что категории отображаются компактными строками без постоянного текста предупреждений под названием.
2. Проверить, что info-кнопка открывает описание категории.
3. Для категории с Warning проверить значок предупреждения и наличие warning в info-flyout.
4. Проверить SAFE/UAC метки, размер и количество файлов в одной строке.
5. Для категории с 0 B кнопка «Очистить» должна быть disabled.
6. Изменить checkbox нескольких категорий: нижняя панель должна обновить количество и суммарный объём.
7. Переключить фильтры «Все / SAFE / ADVANCED»: summary должна учитывать только текущий видимый список, как и «Очистить выбранное».
8. Запустить повторное сканирование: размеры строк и нижняя summary должны обновиться.
9. Прокрутить длинный список: нижняя summary-панель должна оставаться на месте.
10. Проверить «Очистить» у одной категории и «Очистить выбранное» — поведение очистки должно остаться прежним.

## Regression

- Single-instance 0.5.0 работает: второй запуск открывает существующее окно.
- Storage Analyzer cache восстанавливается.
- История очисток ограничена 10 операциями.
- Tray, UAC helper, Settings, Safety и Developer Storage открываются без ошибок.
- `BUILD-INSTALLER.cmd` формирует Setup 0.5.1 с тем же AppId и устанавливает поверх 0.5.0.
