# Safe C: Cleaner 0.6.0 - Embedded Update Manager (Candidate)

- Новая система обновлений не запускает браузер и не вызывает скачанный EXE.
- Проверка использует GitHub REST `/releases/latest`; версии сравниваются численно.
- Скачать можно **только** установщик новой версии с точным именем `SafeCCleaner-Setup-X.Y.Z.exe` и опубликованным SHA-256 (`digest`).
- Загрузка показывает прогресс, допускает отмену, проверяет точный размер и SHA-256.
- Частичные файлы удаляются; успешный файл помещается в пользовательскую папку Downloads.
- Автоматический запуск установщика намеренно запрещён: SHA-256, полученный из того же GitHub API, не является независимым удостоверением издателя. Для автоматической установки необходима доверенная подпись (Authenticode) или независимо подписанный манифест.
- Ветвь без обновления: кнопка загрузки заблокирована; проверка нового релиза доступна вручную.
- `BrowserLauncher.cs` удалён: он больше не используется и содержал компиляционную ошибку `CS1626`.

## Проверки на Windows

1. Запустить `BUILD-WINDOWS.cmd` и `BUILD-INSTALLER.cmd`. Проверить отсутствие CS1626 и WMC9999.
2. При текущем релизе 0.5.2 и установленной тестовой 0.6.0 проверить состояние «актуальная» и заблокированную кнопку загрузки.
3. Проверить отключенный интернет, некорректные JSON/asset/digest, отсутствие скачиваемого EXE.
4. При публикации тестового релиза **новее установленного** проверить прогресс загрузки, отмену, совпадение SHA-256 и папку Downloads.
5. Проверить, что пользовательский EXE не запускается автоматически и существующие операции очистки не затронуты.
