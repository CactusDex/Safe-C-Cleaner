# TEST 0.4.0.1 — Stabilization Patch + Mini Patch 3

1. Запустить приложение в минимальном размере 1240×850.
2. Свернуть NavigationView и открыть «О программе»: карточки не должны выходить вправо за окно; горизонтальной прокрутки быть не должно.
3. Открыть «Настройки» и «О программе»: у нижних NavigationView items не должна отображаться лишняя вертикальная полоса прокрутки.
4. Запустить полное сканирование. Нижний progress bar должен занимать заметную часть панели, ETA не должен терять начало строки (`~1 мин 40 сек`, а не `мин 40 сек`).
5. Нажать «Отмена»: сканирование останавливается штатно.
6. Developer Storage / Docker: при установленном, но не запущенном Docker Desktop должен быть понятный русский статус без сырого `npipe` exception.
7. Developer Storage / NuGet: при наличии `C:\Program Files\dotnet\dotnet.exe` NuGet должен определяться даже если PATH процесса неполный.
8. Developer Storage / npm: проверить обнаружение стандартного `C:\Program Files\nodejs\npm.cmd`; при отсутствии CLI стандартный npm-cache допускается только к read-only анализу.
9. Developer Storage / WSL: `docker-desktop*` не должен считаться обычным пользовательским Linux-дистрибутивом; VHDX анализируется без удаления.
10. Проверить Quick Clean/Deep Clean — поведение safety/cleanup слоя должно совпадать с 0.4.0.
