# TEST 0.4.1 — Storage Analyzer

## Базовый анализ
1. Открыть «Анализатор диска».
2. Нажать «Анализировать C:».
3. Проверить прогресс, примерное ETA и возможность отмены.
4. После завершения проверить общий объём, число файлов/папок и сообщение об ограничениях доступа.

## Результаты
1. Проверить Top 50 и Top 100.
2. Проверить фильтры >500 MB / >1 GB / >5 GB / >10 GB.
3. Проверить категории: образы, архивы, установщики, видео, backup, прочее.
4. Проверить возраст >180 дней и >1 года.
5. Проверить сортировку по размеру, дате и имени.
6. Проверить поиск по имени и полному пути.

## Навигация
1. «Открыть» у файла должен выделить файл в Проводнике.
2. «Открыть» у папки должен открыть папку.
3. «Разобрать» у папки должен перейти в Storage Intelligence и открыть существующий drill-down с breadcrumbs.

## Safety
- Analyzer не должен содержать кнопок удаления.
- Reparse points пропускаются.
- Используются исключения Storage Scanner.
- Отмена не должна очищать предыдущие результаты.
